# 本地微基准

2026-10-16，Windows 10 / CPython 3.11.0，1000 次迭代，使用 perf_counter_ns 与 tracemalloc。工具：`python tools/benchmark.py --iterations 1000`。

| 路径 | 中位数 | P95 |
| --- | --- | --- |
| 本地预算预留并释放 | 45.2 μs | 62.9 μs |
| 创建 Run、调用本地函数、结算并关闭 Run | 1260.35 μs | 1827.9 μs |

tracemalloc 当前 / 峰值观测为 158543 / 211678 字节，包含测量数组。测量时启用了内存跟踪，也存在其他进程负载；不是纯 Wrapper 延迟、内存长期增长证明或生产 SLA。

该微基准不访问供应商、Redis、审计磁盘或网络，不测事件出口吞吐、缓存命中与真实 Redis 往返。正式容量评估需固定硬件与并发、预热、持续运行并分别开启实际部署组件。
