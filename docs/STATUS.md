# 当前交付清单（2026-10-19）

当前版本为 0.1.0 开发交付，前后端可以直接运行。此页列出实际边界，实施计划中未勾选的复合要求不因版本可运行而自动视为完成。

| 模块 | 已实现并在本地验证 |
| --- | --- |
| SDK | 配置校验/快照、本地预算/预留/计费、准入/熔断、同步/异步/流清理 |
| 治理 | 工具额度/幂等/审批、超时、重复/无进展/深度/并发、受约束重试/模型降级；Run 内目标隔离熔断，阈值/恢复时间/容量可在控制台编辑 |
| 内容 | 启发式安全与非流式结构化脱敏、严格 JSON/Schema/文本质量、预算内重试/修复/备用模型/应用人工批准 |
| 缓存 | 默认关闭的模型与版本化只读工具精确缓存；内存/同机 SQLite、签名与身份/版本隔离、TTL/LRU/模型共享租约/重启复用/全连接失效与命中复检；工具命中仍走配额、准入和审计 |
| 遥测 | 白名单元数据、有界批量导出、成功事件/租户采样、错误/拒绝/慢事件保留、可选 OpenTelemetry 终态 span、Prometheus 与普通记录清理 |
| 审计 | SQLite FULL outbox、意图/结果/决定、故障暂停、核对恢复、幂等归档与逻辑保留 |
| 远程策略 | HTTPS/Bearer、HMAC、作用域/版本/TTL、防回退、失联拒绝、只收紧的审计恢复包 |
| 共享预算 | Redis 单作用域 Lua 预留/结算、保守占用、epoch 与审计核对；本地使用 fake Redis Lua 验证 |
| 账本 | USD 估算同步、账单导入/去重、不可变调整、请求关联与服务端金额汇总 |
| 控制台 | 概览、运行、策略、审计、账本、设置六页；工作空间角色授权、内存凭证、精确 CORS |
| 工程 | CLI、一起启动/截图/基准工具、独立 wheel/前端 ZIP、哈希、CI、依赖审计与迁移文档 |

本地门禁：完整环境 615 passed、1 skipped、2 项 subtests；无可选依赖环境 546 passed、20 skipped、2 项 subtests。前端 4 项单测、24 项浏览器 E2E；TypeScript/生产构建通过。真实 Redis 未配置的测试明确跳过；安装包和依赖审计证据见发布说明。

尚未完成的路线图扩展：完整语义防护、网络共享/语义缓存、托管集中遥测与完整尾部采样/OTel 父子上下文传播、第三方框架专用适配器、组织/SSO/浏览器审批队列与跨实例待办、多层共享预算联合事务、多币种与自动供应商账单采集。这些能力没有伪装成已经可调用的 API。

本次新增用法与限制见 [质量恢复](QUALITY.md)、[内容脱敏](CONTENT_SECURITY.md)、[SQLite 缓存](CACHE.md)。人工处理由应用回调提供可信决定，脱敏只支持非流式普通结构，SQLite 共享只适用于同机本地磁盘。

尚需实际环境验收：真实供应商兼容、Redis 主备持久性与 fencing、托管跨平台 CI、生产密钥分发/HTTPS/加密/备份删除、长时间容量测试、公开发布签名。当前没有执行安装包公开发布或公网部署。

运行与恢复见 [OPERATIONS.md](OPERATIONS.md)，验证及安装包见 [RELEASE.md](RELEASE.md)。本机预览使用演示模式，数据来自本地函数；账本中的 SDK 估算与供应商账单分别存储。
